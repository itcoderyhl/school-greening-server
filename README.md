## 【原创】SpringBoot3+Vue3前后端分离的校园绿化管理系统

## 系统介绍

基于SpringBoot3+Vue3前后端分离的校园绿化管理系统，系统包含管理员、工人、用户角色，功能如下：
管理员：首页统计（植被饼状图统计、任务折线图统计）；用户管理；人员管理；植被管理（植被分类、植被管理）；绿化管理（绿化反馈、任务管理、养护管理）；工具管理（工具信息、工具租赁、工具报修）；物资管理（物资信息、物资采购、物资申请）；工资考勤（工资管理、考勤管理）；财务预算；轮播管理；系统留言；公告信息；修改个人资料；修改密码。
工人：植被管理（植被分类查看、植被管理查看）；绿化管理（任务管理、养护管理）；工具管理（工具信息查看、工具租赁、工具报修）；物资管理（物资信息、物资申请）；工资考勤（工资管理、考勤管理）；公告查看；修改个人资料；修改密码。
用户：登录、注册；首页；植被信息（植被分类、植被列表、详情、反馈）；系统留言；通知公告。用户还具有个人中心功能，包括绿化反馈管理、系统留言；个人资料、密码修改。
系统界面美观大方，功能丰富，使用了SpringBoot3、Vue3、Element-Plus、Echarts等技术栈，有需要可提供指导。

项目由本人原创开发，经过多次测试，项目运行无问题，请放心使用，作者QQ：1344127185。

## 使用技术

服务器端技术栈：

- Springboot3
- SpringMvc
- Mybatis
- MySQL

前端技术栈：

- vue3
- element-plus
- axios
- echarts

## 环境介绍

- IDEA集成环境
- JDK17+
- MySQL8.0+

可提供所有运行软件、远程安装、技术指导。
