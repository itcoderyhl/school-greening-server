# school-greening-server
基于SpringBoot3+Vue3前后端分离的校园绿化管理系统，系统包含管理员、工人、用户角色，功能如下： 管理员：首页统计；用户管理；人员管理；植被管理（植被分类、植被管理）；绿化管理；工具管理；物资管理；工资考勤；财务预算；轮播管理；系统留言；公告信息；修改个人资料；修改密码。 工人：植被管理（植被分类查看、植被管理查看）；绿化管理（任务管理、养护管理）；工具管理（工具信息查看、工具租赁、工具报修）；物资管理（物资信息、物资申请）；工资考勤（工资管理、考勤管理）；公告查看；修改个人资料；修改密码。 用户：登录、注册；首页；植被信息（植被分类、植被列表、详情、反馈）；系统留言；通知公告。用户还具有个人中心功能，包括绿化反馈管理、系统留言；个人资料、密码修改。
